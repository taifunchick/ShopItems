## 🎯 What it demonstrates

This project shows **clean architecture principles** in Unity:

| Principle | Implementation |
|-----------|----------------|
| **Data-Driven** | Items stored in ScriptableObjects (no hardcoding) |
| **Separation of Concerns** | Logic (`ShopController`) ≠ UI (`ShopUI`) |
| **Loose Coupling** | Communication via C# Events (no direct references) |
| **Extensibility** | Add new items without touching code |
